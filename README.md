
# Indian Tourism Management System

## Project Introduction

The Indian Tourism Management System is a Python-based
console application designed to help Indian travelers
plan trips and estimate their travel expenses.

## Technologies Used

- Core Python
- Object-Oriented Programming (OOP)
- MySQL
- MySQL Connector for Python

## Main Features

- Admin and Traveler login
- Traveler registration
- Destination management
- Single and multi-destination packages
- Trip itinerary planning
- Estimated travel budget calculation
- Bus, train, own-car and rental-car options
- Booking management
- Wishlist management
- Payment status tracking
- Booking reports

## Database

Database name: indian_tourism_db
